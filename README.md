# 数学讲解师 · 高中数学

> 思考不止，求证不息。

一个可以直接部署到 GitHub Pages 的高中数学教学网页。纯静态、无框架、手机适配。

**课程结构：1 讲「高中数学思维重构课」+ 6 个大板块，每个板块 1 讲完整视频。** 不再拆分课时，不写年级，每个板块只保留标题。

## 一、先解决「点不开」

先说结论：**不是部署的问题。** 部署只是把网页放到公网；卡片、视频弹层、实验能不能点，靠的是浏览器里真正运行这个页面。

如果你之前是在**截图、文件缩略图、代码预览**里点的，那当然点不动——那些不是运行中的网页。

推荐三种打开方式，任选一种：

1. **双击我另外提供的单文件预览版 `math-cosmos-standalone.html`**（最省事，它不在部署文件夹里）
   如果你手上没有这个文件，就用下面两种方式。
2. **双击 `math-cosmos/index.html`**
   需要 `styles.css`、`app.js`、`courses.js` 和它在同一个文件夹里。
3. 在 `math-cosmos` 文件夹里运行：
   ```bash
   python -m http.server 8000
   ```
   然后访问 `http://localhost:8000`。

> 单文件版是给你预览用的；以后改课程请改文件夹里的 `courses.js`。改完后如果还想更新单文件预览，可以让我重新生成，或者直接用文件夹版部署。

## 三、接入视频（每个板块一个总视频）

打开 `courses.js`，会看到两个地方：

```js
featured: {
  id: "thinking",
  name: "高中数学思维重构课",
  // ...
  video: "",
  poster: ""
},

modules: [
  {
    id: "function",
    name: "函数与导数",
    // ...
    video: "",
    poster: ""
  },
  // ...
]
```

- `featured.video`：先导课的视频。
- `modules[i].video`：六个板块各自的视频。

把视频平台后台的「播放器代码 / iframe 代码」整段粘进去：

```js
video: `<iframe src="https://你的播放器地址/embed/xxxx" width="100%" height="100%" frameborder="0" allowfullscreen></iframe>`
```

也可以只填链接：

```js
video: "https://你的播放器地址/embed/xxxx"
```

### 注意事项

- **优先用 iframe 代码。** 如果代码里包含 `<script>`，页面不会执行它；请只保留 `<iframe ...></iframe>` 这一段。
- 视频留空（`video: ""`）会显示「本讲视频即将上线」的预留画面，不会报错。
- 播放地址建议使用 `https://`，否则在 GitHub Pages 上可能被浏览器拦截。
- 如果视频不显示，先检查：是否是 iframe、链接是否完整、视频是否已经转码完成、浏览器是否拦截了第三方 Cookie。
- 想换封面（可选）：给对应板块填 `poster: "images/xxx.jpg"`。不填就自动生成星云渐变封面。
- 想重命名板块：改 `name`；卡片、星图、弹层、阅读进度都会自动更新。`id` 不要改，它是内部标识。

## 四、课程库的结构

- **先导课**：高中数学思维重构课，单独一张宽卡片，放在课程库最上方。
- **六大板块**：函数与导数、三角函数、数列、立体几何、解析几何、概率统计。
- 每张卡片只显示板块标题（加一行英文小字作装饰）和一个「观看视频」入口，不显示年级、难度、时长、标签或课程简介。
- 点整张卡片，或者点卡片上的播放按钮，都会打开视频弹层。
- 弹层里只有：视频、板块标题、「标记为已学」和「下一个板块」（有对应实验的板块会多一个「配合实验」）。
- 已学进度保存在浏览器本地，共 7 讲。

> 首页的数字会自动跟着 `courses.js` 走：6 个大板块、7 讲完整视频。

## 六、换配色

打开 `styles.css` 最上面的 `:root`：

```css
:root {
  --bg: #04060c;        /* 页面底色 */
  --ivory: #f2ede3;     /* 主文字 */
  --gold: #d8b878;      /* 强调色 */
  --gold-bright: #f0d9a8;
  --cyan: #7fd8ff;      /* 辅助色 */
}
```

改 `--gold` 和 `--bg` 就能换整套气质。字体在 `--font-serif` 和 `--font-sans` 里，加载失败会自动回退到系统宋体 / 苹方 / 微软雅黑，不影响使用。

## 七、部署到 GitHub Pages

### 网页上传（推荐）

1. 登录 GitHub，新建一个 **Public** 仓库，例如 `math-class`。
2. 进入仓库，点 **Add file → Upload files**。
3. 把 `math-cosmos` 文件夹里的这些文件拖进去（是文件本身，不是外层文件夹）：
   - `index.html`
   - `styles.css`
   - `app.js`
   - `courses.js`
   - `README.md`
   - `.nojekyll`（如果上传界面看不到它，可以跳过，不影响显示）
4. 点 **Commit changes**。
5. 进入 **Settings → Pages**。
   - Source：**Deploy from a branch**
   - Branch：**main**，目录选 **/ (root)**
   - 点 **Save**
6. 等 1–3 分钟，刷新 Settings → Pages，会看到：
   `https://你的用户名.github.io/math-class/`

以后改课程：在 GitHub 里打开 `courses.js`，点铅笔图标，修改后 **Commit changes**，等一两分钟刷新网页。

### 常见问题

- **打开 404**：确认 `index.html` 在仓库根目录；确认 Pages 分支是 `main`、目录是 `/ (root)`；刚开启需要等一会儿。
- **改了没变化**：按 `Ctrl + F5` 强制刷新；GitHub Pages 本身也有 1–2 分钟延迟。
- **点卡片没反应**：确认你是在浏览器里打开部署后的网址，而不是在看截图/文件缩略图；确认浏览器没有禁用 JavaScript。
- **视频不显示**：检查 iframe 是否完整、视频地址是否以 `https` 开头、浏览器是否拦截第三方内容。
- **想用自己的域名**：Settings → Pages → Custom domain 填写域名，按提示配置 DNS。
- **想部署到国内**：这套文件可以原样上传到 Vercel、Netlify、腾讯云 COS、阿里云 OSS 等任意静态托管。
